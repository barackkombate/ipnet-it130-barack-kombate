# Projet Web IT 130 - Barack KOMBATE

Projet réalisé dans le cadre de l'UE **IT 130 - Introduction aux Technologies Web** à **IPNET Institute of Technology**.

## Contenu du dépôt

- `index.html` : Page d'accueil (Semaine 1)
- `blog.html` : Page de blog structurée avec les balises sémantiques HTML5 (Semaine 2)
- `contact.html` : Page de contact avec formulaire HTML5, tableaux accessibles et intégration vidéo/audio (Semaine 3)
